# Changelog

All notable changes to this project will be documented in this file.

## v0.2.0

### Added

- Added Marble Solitaire as a second playable game.
- Added logic tests for Marble Solitaire.
- Added PWA update checking with `app-version.json`.
- Added safer update behaviour so the app avoids refreshing while the user is inside a game.
- Added improved README project overview and portfolio-style documentation.

### Improved

- Renamed the project to Accessible Games Hub for clearer portfolio presentation.
- Improved PWA manifest name and description.
- Improved elderly-friendly visual accessibility for Marble Solitaire.
- Improved repository metadata with a live app link and topics.
- Improved accessibility notes in the README.

## v0.1.0

### Added

- Added Connect 4 as the first playable game.
- Added phone opponent behaviour.
- Added Easy and Normal phone skill settings.
- Added sound effects and a sound on/off setting.
- Added support contact setup using localStorage.
- Added SMS support message button.
- Added bottom navigation for Games, Support and Settings.
- Added PWA basics, including manifest and service worker.
- Added Connect 4 logic tests.
